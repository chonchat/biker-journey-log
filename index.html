เปิดใช้งานตำแหน่งเพื่อประสบการณ์ขี่รถเต็มรูปแบบ

ทำไม RideMap ถึงต้องขอสิทธิ์ GPS?

RideMap ใช้พิกัดดาวเทียมเพื่อช่วยเหลือนักบิด โดยไม่เก็บข้อมูลการเดินทางส่วนตัวของคุณหากคุณไม่ได้กดปักหมุดบันทึกทริป

แสดงจุดที่คุณอยู่บนแผนที่แบบ Real-time

จุดสีน้ำเงินพร้อมวงแหวนรัศมีความแม่นยำ (Accuracy) ช่วยให้รู้ว่าตอนนี้อยู่บนเส้นทางไหน

ปักหมุดจุดเริ่มต้นทริปและจุดแวะพักด่วน

กดปุ่ม "GPS ปัจจุบัน" ตอนสร้างทริปหรือ Checkpoint พิกัดจะถูกกรอกทันทีโดยไม่ต้องพิมพ์เอง

สำรวจทริปยอดฮิตใกล้ตัว

ดูระยะห่างจากตำแหน่งปัจจุบันไปยังเส้นทางขี่รถสวยๆ และจุดพักรถยอดนิยม

Google Chrome / Microsoft Edge (คอมพิวเตอร์)
  1. คลิกที่ไอคอน 🔒 แม่กุญแจ หรือ การตั้งค่าเว็บไซต์ (Site Settings) ตรงแถบ URL ด้านบนสุด
  2. มองหาหัวข้อ "ตำแหน่ง (Location)" แล้วเปลี่ยนเป็น "อนุญาต (Allow)"
  3. กดรีเฟรชหน้าเว็บ หรือกดปุ่ม "อนุญาตและเปิดใช้งาน GPS ตอนนี้" อีกครั้ง
มือถือ iPhone / iPad (Safari)
  1. เปิดแอป การตั้งค่า (Settings) ของ iPhone > ความเป็นส่วนตัวและความปลอดภัย (Privacy)
  2. เลือก บริการตำแหน่งที่ตั้ง (Location Services) > ตรวจสอบว่าเปิดอยู่
  3. เลื่อนลงเลือก Safari เว็บไซต์ แล้วติ๊กเลือก "ขณะใช้แอป"
มือถือ Android (Chrome)
  1. แตะจุดสามจุด ⋮ มุมขวาบน > การตั้งค่า (Settings) > การตั้งค่าไซต์ (Site settings)
  2. เลือก ตำแหน่ง (Location) แล้วกดเปิดใช้งาน พร้อมอนุญาตให้เว็บไซต์นี้
💡 หมายเหตุสำหรับการเปิดในอุปกรณ์อื่นผ่าน Wi-Fi (HTTP):
เบราว์เซอร์มือถือรุ่นใหม่ส่วนใหญ่จะจำกัดการขอพิกัด GPS ผ่าน Geolocation API เฉพาะ https:// หรือ localhost หากท่านเข้าผ่าน IP เช่น http://192.168.x.x:5500 มือถืออาจปิดกั้นสิทธิ์นี้ ท่านยังคงสามารถใช้โหมดคลิกเพื่อปักหมุดบนแผนที่ได้ตามปกติครับ
